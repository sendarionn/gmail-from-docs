# 実機テスト手順

## 事前条件

- OAuthクライアントIDを設定済み
- Gmail API、Drive API、Docs APIを有効化済み
- テスト用の送信者とメール担当者を用意済み

## Phase 1

1. Gmailで受信メールを開く
2. 「Docsで返信文を作成」が1つだけ表示されることを確認する
3. 別メールへ移動し、ボタンが1つのまま対象が切り替わることを確認する
4. ボタンを押し、件名、送信者、Gmailリンク、元メール、返信領域、社内メモを含むDocsが開くことを確認する
5. 同じメールで再度押し、同じDocsが開くことを確認する

## Phase 2

1. 返信領域へ固有の文章を入力する
2. Docsの保存完了表示を確認する
3. 「Gmailに反映」を押す
4. 元スレッドが開き、返信下書きに固有の文章だけが入ることを確認する
5. 宛先、件名、スレッドが正しいことを確認する
6. 下書きが送信されていないことを確認する

## Phase 3

1. Docsの返信文を変更して再反映し、下書き件数が増えず本文だけ更新されることを確認する
2. 下書きを送信してから再反映し、新しい下書きが作成されることを確認する
3. 共同編集者でDocsを編集できることを確認する
4. 共同編集者のGoogleアカウントでは「Gmailに反映」が所有者不一致で拒否されることを確認する
5. 認可を取り消し、再認証の案内が表示されることを確認する
6. 複数Googleアカウントで所有者以外のメールボックスを操作しないことを確認する

結果、Chromeバージョン、Workspaceドメイン、Gmail表示言語を記録する
